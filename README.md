# Messaging App

A lightweight messaging app built with Express and vanilla JavaScript.

## Features

- User registration and login
- Private messaging between users
- Profile customization with display name, status, bio, and accent color
- Persistent data stored in `data/store.json`

## Run locally

1. Install dependencies:
   `npm install`
2. Start the app:
   `npm start`
3. Open `http://localhost:3000` in your browser

## Notes

The app uses browser sessions and local JSON storage, so it is intended for local development and quick demos.
